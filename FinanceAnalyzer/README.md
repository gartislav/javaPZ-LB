# Фінансовий аналізатор
Java 21, Maven, Lombok, JUnit 5.
Відкрийте pom.xml в IntelliJ IDEA, оберіть JDK 21, дочекайтеся імпорту Maven. Запустіть Main. Для локального запуску задайте Program arguments: `sample.csv 01-2024 2023-12-01 2024-01-31`. Робоча папка — корінь проекту. CSV sample.csv — демонстраційний, не повна копія джерела. Тести: Maven → Lifecycle → test або `mvn test`.
